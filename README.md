# 🍅 番茄钟

一个零依赖、零构建、单文件的番茄钟 Web 应用。打开 `番茄钟.html` 就能用。

## ✨ 特性

- **三种模式自动循环**：专注 25 分钟 → 短休息 5 分钟 / 长休息 15 分钟
- **完成 4 个专注后进入长休息**（经典番茄工作法）
- **可视化进度环**（SVG 实现，柔和颜色切换）
- **可自定义时长**（右上角 ⚙ 设置）
- **每完成自动播放提示音**（Web Audio 合成，无需音频文件）
- **每日统计**：完成轮数 + 累计专注分钟数
- **键盘快捷键**：`空格` 开始/暂停，`R` 重置
- **完全离线可用**，不联网、不收集数据

## 🚀 使用方法

### 直接打开

双击 `番茄钟.html` 用浏览器打开即可。

### 本地启动（推荐）

部分浏览器对 `file://` 协议有限制，建议起个本地服务器：

```bash
# Python 3
python3 -m http.server 8000

# 或者 Node.js
npx serve
```

然后访问 http://localhost:8000

## 🎮 操作

| 操作 | 鼠标 | 键盘 |
|---|---|---|
| 开始 / 暂停 | 点击中间红色按钮 | `空格` |
| 重置当前阶段 | 点击"重置" | `R` |
| 跳过当前阶段 | 点击"跳过" | — |
| 切换模式 | 点击顶部三个按钮 | — |
| 调整时长 | 右上角 ⚙ | — |

## 🎨 配色

莫兰迪温柔色系：

| 用途 | 颜色 |
|---|---|
| 页面背景 | `#FBE6D6` 米色 |
| 专注模式 | `#76A492` 深绿 |
| 短休息 | `#C3D2C2` 浅绿 |
| 长休息 | `#E9C8C3` 粉 |
| 文字主色 | `#65505C` 深紫 |

## 🛠️ 技术栈

- 纯 HTML + CSS + JavaScript（vanilla）
- 零依赖、零打包
- SVG 绘制进度环（`stroke-dasharray` + `stroke-dashoffset`）
- Web Audio API 合成提示音
